Sign Docs

Плагин фиксирует подписанные PDF-документы организации в WordPress: хранит исходный файл как контрольную копию, рассчитывает серверный SHA-256, создает запись CPT sign-docs и показывает публичную страницу проверки.

Ключевые инварианты

  • Исходный PDF после подписания не изменяется.
  • Серверный SHA-256 является главным источником истины.
  • Публичная PDF-копия может содержать визуальную отметку, QR-код и человекочитаемые данные.
  • QR-код ведет на страницу проверки, а не напрямую на PDF.
  • Повторная подпись должна создавать новую версию, не перезаписывая предыдущую.

Модули

  • Session Handoff - current state, recent changes, checks and next steps.
  • Plugin - координация загрузки модулей и lifecycle hooks.
  • Post Type - регистрация CPT sign-docs.
  • Meta - контракт метаданных документа.
  • Taxonomies - типы документов и подразделения.
  • Storage - структура файлового хранилища и SHA-256.
  • Document Service - создание записи документа из PDF.
  • REST API - двухфазный workflow браузерного штампа.
  • AI Metadata - автозаполнение реквизитов по тексту первой страницы PDF.
  • Title Template - матрица сборки названия документа по категории, типу и реквизитам.
  • Admin Upload JS - наложение штампа через pdf-lib.
  • Gutenberg Blocks - блок редактора для выбора, подписи и вывода документов.
  • Settings - значения по умолчанию для подписи, штампа, QR-кода и кнопок блока.
  • Site Icon - PNG-кэш favicon или логотипа для QR-кода.
  • Verification Page - публичная страница проверки.
  • Admin - административные колонки и экран добавления одного документа.
  • Usage Index - индекс использования блока документа в записях и страницах.
