Module: Admin Upload JS

Модуль assets/js/admin-upload.js накладывает штамп на PDF в браузере администратора.

Входные данные

  • Исходный PDF из file input.
  • Реквизиты конструктора названия: категория, вид документа, институция, дата, номер и название в кавычках.
  • Ответ REST prepare: SHA-256, URL проверки, дата подписи, подписант и параметры штампа.
  • URL site icon или fallback-логотипа сайта для вставки в центр QR-кода.

Выходные данные

  • PDF с компактным текстовым штампом без фоновой заливки.
  • Компактный footer-штамп на остальных страницах.
  • QR-код страницы проверки с тем же цветом и прозрачностью, что и текст штампа.
  • Favicon или логотип сайта в центре QR-кода, если он задан в WordPress. Обычно используется серверный PNG-кэш; WebP-конвертация через canvas остается только fallback-вариантом.
  • Кликабельная область поверх QR-кода и ID записи.
  • Автоматически собранное краткое и полное название документа до отправки формы.

Контракт

  • Штамп создается через локальный assets/vendor/pdf-lib.min.js.
  • Кириллица выводится настоящим PDF-текстом через fontkit и шрифт Golos Text.
  • Внутренний отступ штампа минимальный, межстрочный интервал около 1.25 строки.
  • Базовый размер шрифта и длина штампа берутся из настроек и фиксируются в meta документа.
  • Рамка основного штампа рисуется только если включена настройка stamp_border_enabled.
  • Логотип в QR вставляется только если включена настройка qr_logo_enabled.
  • QR создается через локальный assets/vendor/qrcode.min.js и всегда ведет на страницу проверки.
  • Клиентский stamped PDF не влияет на серверный SHA-256 исходника.
  • Кнопки регистра меняют только поле названия в кавычках; итоговое название остается редактируемым вручную.
  • SHA-256 не выводится в основном штампе, но печатается в нижней строке для технической сверки.
