Module: Admin Upload JS

Модуль assets/js/admin-upload.js — браузерный скрипт страницы добавления документа. Накладывает штамп на PDF через pdf-lib, извлекает текст первой страницы через PDF.js, запрашивает AI-подсказки и управляет формой.

Основные функции

  • Перехват кнопки «Сохранить и подписать»: вместо POST-отправки формы вызывает REST /prepare, штампует PDF в браузере, отправляет /complete.
  • Кнопка «Сохранить без подписи»: отправляет форму традиционным POST.
  • Предпросмотр PDF в iframe через blob URL (файл не загружается на сервер).
  • Ручной выбор места штампа: crosshair-слой поверх предпросмотра, координаты сохраняются как stamp_manual_x/stamp_manual_y (0..1).
  • Извлечение текста первой страницы через локальный PDF.js для AI-автозаполнения.
  • Автоматическая сборка названия документа по клиентской копии title rules (SignDocsUpload.titleRules).
  • Кнопки регистра (sentence case).
  • Год/период: быстрые варианты от текущей даты (текущий год, следующий учебный год и т.д.).
  • Добавление институции в название.
  • AI-подсказки для полей формы (не перетирают вручную изменённые поля).

Создание штампа

  • Штамп создаётся через assets/vendor/pdf-lib.min.js.
  • Текст выводится через fontkit и встроенный шрифт Golos Text.
  • Основной штамп на первой странице; компактный footer-штамп на остальных.
  • QR-код генерируется через assets/vendor/qrcode.min.js.
  • Favicon/логотип накладывается на модули QR (серверный PNG-кэш или canvas fallback).
  • Кликабельная область поверх QR-кода + ID записи.
  • В нижней строке штампа печатается SHA-256 исходника.

Зависимости от vendor-файлов

  • Если pdf-lib.min.js, fontkit.umd.min.js, qrcode.min.js и Golos Text .ttf отсутствуют — hasVendor=false, скрипт не пытается штамповать.
  • PDF.js (pdf.min.mjs + pdf.worker.min.mjs) для извлечения текста может отсутствовать отдельно.

Контракт

  • Клиентский stamped PDF не влияет на серверный SHA-256 исходника.
  • AI-подсказка не перетирает поля, изменённые после выбора файла.
  • Если извлечённый текст короче 40 символов, AI-запрос не выполняется.
  • Файл не загружается на сервер до отправки формы или REST prepare.
