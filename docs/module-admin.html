Module: Admin

Модуль includes/class-admin.php отвечает за административные представления документа: список, карточку, экран добавления, фильтры, архивирование и замену.

Список документов

  • Колонка статуса (с русской подписью).
  • Фильтры по таксономиям: категория, тип, институция, подразделение.
  • Фильтр использования (Usage Index).
  • Row actions: Заменить, Архивировать (вместо корзины/удаления).
  • Bulk actions: корзина и удаление скрыты.

Карточка документа (meta boxes)

  • «Данные документа»: название, категория, тип, институция, дата, номер, тема, статус, версия, подписант.
  • «Файлы и проверка»: ссылки на страницу проверки, stamped PDF, оригинал, SHA-256, audit-поля завершения.
  • «Параметры штампа»: угол, цвет, прозрачность, размер шрифта, ширина, рамка, расположение, логотип в QR.
  • Submitbox: ссылка «Заменить новым PDF» и «Архивировать документ».

Экран добавления документа

Единый пункт меню Sign Docs → Добавить документ. Стандартный post-new.php перенаправляется сюда.

  • Двухколоночный интерфейс: форма слева, предпросмотр PDF справа.
  • Drag-and-drop или выбор PDF через file input.
  • Реквизиты: категория, вид документа (с группировкой по категории), институция (выбор из справочника или ввод новой), дата, номер, название.
  • Автозаполнение года/периода от даты подписания.
  • Предпросмотр PDF в iframe (blob URL, файл не загружается на сервер).
  • Ручной выбор места штампа на предпросмотре первой страницы.
  • Две кнопки сохранения: «Сохранить и подписать документ» (через JS + REST prepare/complete) и «Сохранить без подписи» (традиционный POST, статус unsigned).
  • При замене документа показывается предупреждение о предыдущей записи.

Архивирование и защита от удаления

  • pre_trash_post и pre_delete_post заменяют удаление на установку document_status=archived.
  • Исключение: внутренний rollback сервиса (is_rollback_delete_in_progress) выполняет настоящее удаление неполной записи.
  • Стандартный trash и delete action скрыты из row-actions и bulk-actions.

Контракт

  • Модуль не копирует файлы и не считает хеш — делегирует Document Service.
  • Подписант и параметры штампа берутся из настроек, а не из формы.
  • Действие «Заменить» открывает форму добавления с replaces_post_id.
  • Server-side POST всегда сохраняет документ как unsigned; браузерная подпись идёт через REST API.
  • Файлы не загружаются на сервер до отправки формы.
  • AI-автозаполнение — подсказка; администратор может изменить все поля.
