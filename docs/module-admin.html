Module: Admin

Модуль includes/class-admin.php отвечает за административные представления документа и ручную загрузку одного PDF.

Входные данные

  • Список и карточка записей CPT sign-docs.
  • Meta-поля документа, файлов, подписи, проверки и параметров штампа.
  • Таксономии sign_doc_category, sign_doc_type, sign_doc_department и sign_doc_institution.
  • Форма загрузки PDF с nonce, категорией, типом, датой, номером, темой и полным названием документа.
  • Настройки штампа из Sign_Docs_Settings.

Выходные данные

  • Дополнительные колонки в таблице документов.
  • Короткий вывод хеша для быстрого контроля.
  • Нативные dropdown-фильтры WordPress по таксономиям на странице списка документов.
  • Meta boxes на карточке документа: данные документа, файлы и проверка, параметры штампа.
  • Единый пункт меню Добавить документ, создающий запись через Sign_Docs_Document_Service и сразу подписывающий PDF.
  • Альтернативная кнопка Сохранить без подписи, сохраняющая только исходный PDF без публичной копии со штампом.
  • Drag-and-drop поле выбора PDF с открытием проводника по щелчку.
  • Двухколоночный интерфейс: форма слева, локальный предпросмотр PDF и инструменты штампа справа.
  • Дублированные верхние и нижние кнопки сохранения.
  • Автозаполнение краткого названия из имени выбранного PDF, если поле еще пустое.
  • Для локальных актов институция подставляется из настроек организации и скрывается из формы; отдельный чекбокс позволяет добавить ее в конструктор названия.
  • Для внешних документов поле институции остается комбинированным вводом: dropdown существующих терминов и отдельное поле для нового краткого наименования в родительном падеже.
  • Ручной выбор места штампа в просмотре PDF с сохранением нормализованных координат первой страницы.
  • Пункт меню Настройки, ведущий на страницу реквизитов штампа.

Контракт

  • Модуль не копирует файлы самостоятельно и не считает хеш.
  • Предпросмотр использует браузерный blob: URL и не загружает файл на сервер до отправки формы или REST prepare-запроса.
  • Ручные координаты штампа считаются относительно слоя с пропорциями первой страницы PDF; для пиксельной проверки рендера страницы нужен последующий переход на canvas-рендер через PDF.js.
  • Фильтр таксономии выводится только если в таксономии есть хотя бы один термин.
  • Карточка документа показывает meta-поля как данные регистрации, а не как произвольный Gutenberg-контент.
  • Форма подписи не показывает редко меняемые реквизиты: подписант, организация и параметры штампа берутся из настроек.
  • Стандартное удаление документа заменяется переводом meta document_status в archived.
  • После подписи админка остается на странице добавления документа и показывает ссылку на страницу проверки.
  • Документы без подписи получают статус unsigned и не запускают клиентскую генерацию штампа.
  • Пакетная загрузка будет добавлена отдельным экраном, чтобы не смешивать массовый workflow с простой формой.
