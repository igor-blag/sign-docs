Module: AI Metadata

Модуль includes/class-ai-metadata.php автозаполняет реквизиты документа по тексту первой страницы PDF. Он не подписывает файл и не меняет контрольную копию; результат — подсказка для формы загрузки.

Регистрация AI ability

  • register_ability_category() — регистрирует категорию sign-docs в WP Abilities API.
  • register_abilities() — регистрирует ability sign-docs/suggest-document-metadata с input/output schema, permission и execute callback.
  • Ability помечена как readonly, не-destructive, не-idempotent, доступна через REST.

Входные данные

  • Текст первой страницы PDF (извлечён в браузере через локальный PDF.js).
  • Имя исходного файла PDF.
  • Настройки организации из Sign_Docs_Settings.
  • Текущие термины таксономий: категории, типы, институции.

Выходные данные

  • REST endpoint POST /wp-json/sign-docs/v1/suggest-metadata.
  • JSON: category, type_label, type_term_id, institution, date, number, subject, post_title, confidence (0..1), warnings.

Модель и провайдер

  • Предпочитаемый провайдер: openrouter (если настроен).
  • Единственная предпочитаемая модель: google/gemini-2.5-flash-lite.
  • Для OpenRouter передаётся reasoning: {"exclude": true}.
  • Ответ запрашивается как JSON через as_json_response() с required-полями.
  • Нормализация ответа: проверка category по существующим slug, сопоставление type по term_id или label, удаление лишних символов.

Контракт

  • Включается настройкой ai_autofill_enabled (по умолчанию выключено).
  • Минимальная длина текста — 40 символов (compact_text() нормализует пробелы и пустые строки).
  • Если AI не отвечает или возвращает ошибку, форма остаётся ручной.
  • Если пользователь изменил поля после выбора файла, браузер не перетирает их ответом AI.
  • Патчи OpenRouter provider-плагина находятся вне репозитория плагина.
