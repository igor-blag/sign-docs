Module: Gutenberg Blocks

Модуль includes/class-blocks.php регистрирует динамический блок sign-docs/document и подключает editor/public assets для работы с документами в Gutenberg.

Атрибуты блока

  • postId (number) — ID записи sign-docs.
  • title, fullTitle (string) — кешированные названия для редактора.
  • verificationUrl, stampedFileUrl, originalFileUrl (string) — URL для редактора.
  • sha256Hash (string) — SHA-256 для редактора.
  • linkText (string) — текст ссылки (по умолчанию — название документа).
  • openInNewTab (boolean) — открывать ссылку в новой вкладке.
  • showIcon (boolean, default true) — показывать иконку документа.
  • showMeta (boolean) — показывать строку статуса/даты/версии.
  • displayMode (string) — link, button или card.
  • showDownloadButton (boolean) — показывать кнопку скачивания stamped PDF.
  • showEmbeddedPdf (boolean) — показывать iframe со stamped PDF.
  • showSignatureButton (boolean, default true) — показывать кнопку/ссылку сведений о подписи.
  • statusLabel, signedAt, documentVersion (string) — кешированные meta для редактора.

Фронтенд-рендер

  • Выводит название (ссылку на stamped PDF или статичный текст), иконку, meta-строку.
  • Кнопки: «Скачать» (stamped PDF), кнопка-сведения (details popover с ID, датой, подписантом, SHA-256, ссылками).
  • Опциональный iframe со stamped PDF.
  • Для недействующих статусов (archived, replaced, needs_public_copy) скачивание, оригинал и iframe скрыты; показывается предупреждение и ссылка на страницу проверки.
  • Название всегда актуальное из базы (не из атрибута).
  • Дата в popover форматируется в MSK.

Редактор

  • Полноэкранная модалка добавления документа: dropzone, предпросмотр, выбор места штампа, конструктор названия, категория/тип/институция.
  • Поиск существующих документов через REST endpoint sign-docs/v1/documents.
  • Команда «Upload replacement PDF» — создаёт новый документ с replaces_post_id и выбирает его в блоке.
  • Vendor-скрипты (pdf-lib, qrcode, fontkit, Golos Text) подключаются, если есть на диске.

Контракт

  • Блок ведёт себя близко к core-блоку «Файл».
  • После успешной подписи новый CPT сразу выбирается в блоке.
  • На фронте клик по названию открывает stamped PDF; сведения открываются локально в popover.
  • Если выбранная запись не опубликована или не sign-docs, блок ничего не выводит.
