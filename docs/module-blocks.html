Module: Gutenberg Blocks

Модуль includes/class-blocks.php регистрирует динамический блок sign-docs/document и подключает editor/public assets для работы с документами прямо в Gutenberg.

Входные данные

  • Выбранная запись sign-docs, сохраненная в атрибуте postId.
  • PDF-файл и реквизиты документа из полноэкранной модалки добавления.
  • Поиск загруженных документов по строке, статусу, категории, типу документа и подразделению.
  • Настройки отображения блока: текст подписи, режим внешнего вида, режим взаимодействия, иконка, meta, выравнивание, кнопка скачивания и встроенный PDF.
  • REST endpoint sign-docs/v1/documents для выбора существующих документов.
  • REST endpoints sign-docs/v1/prepare и sign-docs/v1/complete для создания нового подписанного CPT без выхода из редактора.

Выходные данные

  • Durable-атрибут postId и кешированные editor-атрибуты title, fullTitle, verificationUrl, stampedFileUrl, originalFileUrl, sha256Hash.
  • Фронтенд-рендер с актуальным полным названием из базы, а не только из сохраненного HTML блока.
  • Режим title-details: название открывает карточку сведений, не переводя пользователя на страницу проверки.
  • Режим buttons: название выводится статично, рядом показываются кнопки Скачать и Сведения.
  • Опциональный iframe со stamped PDF, если включен атрибут showEmbeddedPdf.

Контракт

  • Блок должен вести себя близко к core-блоку Файл: можно выбрать существующий документ, добавить новый, изменить подпись, включить кнопку скачивания и встроенный PDF.
  • Кнопка Add document не должна перезагружать Gutenberg и не должна переводить пользователя на admin-страницу добавления.
  • После успешной подписи новый CPT сразу выбирается в том же блоке.
  • Полноэкранная модалка добавления повторяет основные функции admin-страницы: dropzone PDF, предпросмотр, выбор места штампа, конструктор названия и фильтрацию типов по категории.
  • Серверный SHA-256 из REST workflow остается источником истины.
  • На фронте блок не ведет пользователя по клику на название на страницу проверки; сведения открываются локально в карточке.
  • Карточка сведений может показывать статус, дату подписи, версию, SHA-256, ссылку на stamped PDF, ссылку на оригинал и ссылку на страницу проверки.
  • Если выбранная запись удалена, не опубликована или не является sign-docs, фронтенд ничего не выводит.
