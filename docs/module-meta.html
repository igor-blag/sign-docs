Module: Meta

Модуль Sign_Docs_Meta задаёт контракт метаданных документа через register_post_meta() для CPT sign-docs.

Регистрируемые поля

  • full_title (string) — полное название документа.
  • document_comment (string) — внутренний комментарий администратора.
  • original_file_path, original_file_url (string) — контрольная копия.
  • stamped_file_path, stamped_file_url (string) — публичная копия с отметкой.
  • stamped_file_hash (string) — SHA-256 публичной копии.
  • sha256_hash (string) — серверный SHA-256 исходного файла.
  • signed_at (string) — дата и время подписи.
  • signer_name, signer_position, signer_organization (string) — подписант.
  • signer_user_id (integer) — ID пользователя, создавшего запись.
  • verification_url, qr_code_data (string) — данные проверки и QR.
  • prepared_at (string) — дата подготовительной фазы.
  • completed_at (string), completed_by_user_id (integer), completed_ip (string), completed_user_agent (string) — audit-поля завершения.
  • document_status (string) — active, unsigned, needs_public_copy, archived, replaced, draft.
  • document_version (integer) — номер версии.
  • replaces_post_id, replaced_by_post_id (integer), replacement_note (string) — связь замены.
  • source_filename (string) — имя исходного загруженного файла.
  • file_size (integer) — размер исходного файла.
  • mime_type (string) — MIME-тип.
  • file_basename (string) — транслитерированное имя файла для файловой системы.
  • document_category, document_type_label, document_type_term_id, document_institution (string/integer) — реквизиты классификации.
  • document_date, document_number, document_subject, academic_year (string) — реквизиты документа.
  • stamp_position (string) — устаревшее поле (не используется).
  • stamp_corner, stamp_color, stamp_opacity, stamp_font_size, stamp_border_enabled (string/integer) — параметры штампа. Ширина штампа не хранится и вычисляется автоматически по содержимому.
  • stamp_placement_mode (string) — corner или manual.
  • stamp_manual_x, stamp_manual_y (string) — ручные координаты штампа (0..1).
  • qr_logo_enabled (string) — флаг наложения логотипа на QR.

REST-схема

Поля original_file_path, stamped_file_path, sha256_hash, qr_code_data, completed_ip, completed_user_agent, signer_user_id, completed_by_user_id исключены из show_in_rest и доступны только серверному коду.

Контракт

  • Неизвестные meta keys не читаются helper-методом get().
  • REST-доступ к meta проверяется через edit_post конкретной записи.
  • Целочисленные поля проходят через absint().
  • Многострочные текстовые поля (full_title, document_comment, replacement_note) — через sanitize_textarea_field(), остальные строковые — через sanitize_text_field().
