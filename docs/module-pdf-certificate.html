Module: PDF Certificate

Модуль Sign_Docs_Pdf_Certificate создает минимальный публичный PDF с данными проверки.

Входные данные

  • Путь для записи stamped.pdf.
  • Название документа, дата подписи, подписант, организация.
  • SHA-256 исходного PDF.
  • URL страницы проверки и исходное имя файла.

Выходные данные

  • Валидный PDF 1.4 с сертификатом проверки.
  • Человекочитаемые данные для сверки с публичной страницей.

Контракт

  • Модуль не изменяет исходный PDF.
  • Модуль не объединяет страницы исходного PDF с отметкой.
  • Текст сертификата выводится в ASCII/translit, так как поддержка кириллицы требует отдельного встраивания шрифта.
  • Следующая версия должна заменить этот модуль или расширить его полноценным stamp-overlay поверх исходного PDF.
