Module: Plugin

Класс Sign_Docs_Plugin — точка сборки плагина. Загружает все модули, регистрирует WordPress hooks, управляет активацией/деактивацией и проверкой версии.

Загружаемые модули

  • Post Type, Taxonomies, Meta, Storage, Translit, Site Icon, Title Template
  • Document Service, AI Metadata, REST Controller, Verification Page
  • Settings, Admin, Blocks, Usage Index

Activation

  • Регистрирует CPT и таксономии.
  • Создаёт директории uploads/sign-docs/ и uploads/sign-docs/assets/.
  • Создаёт таблицу {prefix}sign_docs_usage через dbDelta.
  • Назначает capability sign_docs_upload_documents администраторам.
  • Фиксирует версию плагина в опции sign_docs_version.
  • Сбрасывает rewrite rules.

Upgrade check

maybe_upgrade() вызывается на admin_init. Если версия в опции отличается от SIGN_DOCS_VERSION, обновляет структуру таблицы индекса и версию в опции.

Deactivation

Только сбрасывает rewrite rules. Данные (CPT, таблицы, файлы, опции) не удаляются.

Hooks, регистрируемые в boot()

  • init — CPT, Taxonomies, Meta, rewrite rules, Blocks.
  • post_type_link — verification permalink.
  • the_content — verification page render.
  • wp_enqueue_scripts — public assets (verification page, blocks).
  • manage_sign-docs_posts_columns — колонки статуса и использования.
  • restrict_manage_posts — фильтры таксономий и использования.
  • pre_get_posts — применение фильтра использования.
  • add_meta_boxes_{sign-docs} — meta boxes на карточке.
  • admin_init — settings, title rules, upgrade, backfill, redirect add-new.
  • admin_menu — submenu pages, скрытие таксономий.
  • admin_post_sign_docs_upload, admin_post_sign_docs_archive — обработчики форм.
  • admin_enqueue_scripts — admin JS/CSS.
  • post_submitbox_misc_actions — archive/replace в submitbox.
  • admin_head-post.php — скрытие кнопки удаления.
  • post_row_actions, bulk_actions — кастомные действия.
  • pre_trash_post, pre_delete_post — archive instead of trash.
  • rest_api_init — REST routes.
  • wp_abilities_api_categories_init, wp_abilities_api_init — AI ability.
  • enqueue_block_editor_assets — block editor assets.
  • save_post, before_delete_post, transition_post_status — usage index.

Контракт

  • Модуль не содержит бизнес-логику.
  • boot() идемпотентен (флаг $booted).
  • dbDelta для таблицы индекса не запускается на каждом init.
