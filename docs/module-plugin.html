Module: Plugin

Класс Sign_Docs_Plugin является точкой сборки плагина.

Входные данные

  • WordPress hooks: plugins_loaded, activation, deactivation.
  • Константы путей, заданные в sign-docs.php.

Выходные данные

  • Зарегистрированные callbacks для CPT, таксономий, meta, публичной страницы, REST API, AI ability и админки.
  • Созданные директории хранилища при активации.
  • Созданная или обновленная таблица индекса использования при активации и upgrade-check по версии плагина.
  • Обновленные rewrite rules при активации и деактивации.

Контракт

  • Модуль не содержит бизнес-логику подписи.
  • AI-логика живет в Sign_Docs_AI_Metadata; координатор только загружает файл класса и регистрирует hooks.
  • Модуль не работает напрямую с загружаемыми файлами, кроме вызова setup-функций при активации.
  • dbDelta для таблицы индекса использования не запускается на каждом init; структура БД обновляется только при активации или изменении версии.
  • Повторный вызов boot() не должен дублировать регистрацию hooks.
