Module: Post Type

Модуль includes/class-post-type.php регистрирует CPT sign-docs, который хранит запись о подписанном документе.

Входные данные

  • Хук WordPress init.

Выходные данные

  • Публичный тип записи sign-docs.
  • Публичный rewrite CPT отключен; URL проверки формируется отдельным правилом /signed/{post_id}/.
  • Классический экран редактирования без Gutenberg-редактора.
  • Поддержка только системных полей title и author; остальные данные выводятся через meta boxes.

Контракт

  • CPT хранит данные документа, но не хранит файл внутри медиа-библиотеки WordPress.
  • Публичная страница записи является страницей проверки.
  • Произвольный контент Gutenberg не используется: запись является карточкой документа, а не редакционной страницей.
  • Удаление и версии будут ограничены отдельным модулем lifecycle при развитии проекта.
