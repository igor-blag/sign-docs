Module: REST API

Модуль Sign_Docs_REST_Controller реализует двухфазную подпись PDF с наложением штампа в браузере и предоставляет данные для Gutenberg-блока.

documents

GET /wp-json/sign-docs/v1/documents

  • Возвращает опубликованные записи sign-docs для модалки выбора.
  • Поддерживает фильтры: search, status (document_status), category, type, department, page, per_page, include.
  • Возвращает: id, title, verificationUrl, stampedFileUrl, originalFileUrl, status, signedAt, documentVersion, replacesPostId, replacedByPostId, sha256Hash, type, department.
  • Доступ: edit_posts.

prepare

POST /wp-json/sign-docs/v1/prepare

  • Принимает мультипарт-форму: original_pdf (файл), реквизиты документа, save_mode (signed/unsigned), replaces_post_id.
  • При save_mode=unsigned или document_category=external-regulation подписант очищается, статус unsigned.
  • Вызывает Sign_Docs_Document_Service::prepare_from_local_pdf().
  • Сохраняет исходник как контрольную копию, считает SHA-256.
  • Создаёт приватную запись со статусом needs_public_copy (или unsigned).
  • Возвращает данные для браузерного штампа: все параметры штампа (цвет, прозрачность, угол, ширина, рамка, ручные координаты, логотип в QR).
  • Доступ: sign_docs_upload_documents.

complete

POST /wp-json/sign-docs/v1/complete

  • Принимает post_id и stamped_pdf (файл).
  • Вызывает Sign_Docs_Document_Service::complete_with_stamped_pdf().
  • Проверяет: запись существует, статус needs_public_copy, исходник на месте, SHA-256 совпадает, verification data не пуста.
  • Сохраняет stamped.pdf, переводит документ в active, публикует, применяет замену (replaces).
  • Доступ: sign_docs_upload_documents + edit_post для конкретной записи.

suggest-metadata

POST /wp-json/sign-docs/v1/suggest-metadata

  • Принимает first_page_text (обязательно) и source_filename.
  • Вызывает ability sign-docs/suggest-document-metadata.
  • Возвращает: category, type_label, type_term_id, institution, date, number, subject, post_title, confidence, warnings.
  • Доступ: sign_docs_upload_documents.

Контракт

  • Write-endpoints доступны только пользователям с sign_docs_upload_documents.
  • complete дополнительно требует edit_post для конкретной записи.
  • Юридически значимым остаётся хеш исходной контрольной копии.
  • Stamped PDF — публичный визуальный артефакт, не источник истины.
