Module: REST API

Модуль Sign_Docs_REST_Controller реализует двухфазную подпись PDF с наложением штампа в браузере и предоставляет данные для Gutenberg-блока.

documents

GET /wp-json/sign-docs/v1/documents

  • Возвращает опубликованные записи sign-docs для модалки выбора загруженного документа.
  • Поддерживает фильтры поиска, статуса, категории, типа документа, подразделения, страницы и размера страницы.
  • Возвращает title, full title, verification URL, stamped/original file URLs, SHA-256, статус, дату подписи и версию.
  • Возвращает списки фильтров по таксономиям для editor UI.

prepare

POST /wp-json/sign-docs/v1/prepare

  • Принимает исходный PDF, реквизиты документа, категорию, тип, институцию, дату, номер, тему и данные подписанта.
  • Сохраняет исходник как контрольную копию.
  • Считает серверный SHA-256.
  • Создает запись sign-docs со статусом needs_public_copy.
  • Возвращает данные для браузерного штампа: hash, URL проверки, дату, подписанта.
  • Возвращает параметры штампа, включая угол, цвет, прозрачность, размер шрифта, ширину, рамку и данные QR-кода.

complete

POST /wp-json/sign-docs/v1/complete

  • Принимает post_id и готовый stamped.pdf.
  • Сохраняет публичную копию рядом с исходником в uploads/sign-docs/year/month/post-id/stamped.pdf.
  • Переводит документ в статус active и публикует запись.

suggest-metadata

POST /wp-json/sign-docs/v1/suggest-metadata

  • Принимает first_page_text и необязательный source_filename.
  • Вызывает ability sign-docs/suggest-document-metadata.
  • Возвращает JSON-подсказки для категории, типа документа, даты, номера, темы, институции и названий.
  • Используется только админским JavaScript после локального извлечения текста из первой страницы PDF.

Контракт

  • Write-endpoints доступны только пользователям с правом upload_files.
  • Endpoint выбора документов доступен пользователям, которым разрешено редактировать записи в редакторе.
  • Endpoint AI-подсказок доступен пользователям с правом upload_files.
  • Юридически значимым остается hash исходной контрольной копии.
  • Stamped PDF является публичным визуальным артефактом и не используется как источник истины.
