Module: Settings

Модуль includes/class-settings.php хранит постоянные настройки плагина: реквизиты подписанта, параметры PDF-штампа, поведение QR-кода, AI-автозаполнение и базовое оформление кнопок блока.

Хранимые значения

  • signer_name, signer_position — ФИО и должность подписанта.
  • signer_organization — организация (по умолчанию — название сайта).
  • stamp_corner — угол штампа (top-left, top-right, bottom-left, bottom-right).
  • stamp_color — цвет штампа (hex).
  • stamp_opacity — прозрачность (0.1..1).
  • stamp_font_size — размер шрифта (6..12 pt).
  • stamp_border_enabled — рамка вокруг штампа.
  • qr_logo_enabled — наложение favicon/логотипа на QR.
  • button_primary_color, button_primary_text_color, button_outline_color — цвета кнопок блока.
  • button_border_radius — скругление кнопок (0..9999 px).
  • ai_autofill_enabled — флаг AI-подсказок на странице загрузки.
  • upload_user_ids — не хранится в опции, а управляет capability sign_docs_upload_documents для пользователей с ролью editor.

Права на загрузку

  • Администраторы всегда имеют capability sign_docs_upload_documents.
  • Редакторам право выдаётся через чекбоксы на странице настроек.
  • sync_upload_users() добавляет/удаляет capability при сохранении настроек.

Контракт

  • Настройки являются defaults и копируются в meta конкретной записи при подписи.
  • Изменение настроек не меняет реквизиты старых документов.
  • Серверная санитизация: цвет → hex, прозрачность 0.1..1, шрифт 6..12, ширина 70..160, скругление 0..9999.
  • AI-автозаполнение не заменяет ручную проверку.
  • QR-код всегда ведёт на страницу проверки.
  • Сохранять настройки может только manage_options.
