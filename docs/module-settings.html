Module: Settings

Модуль includes/class-settings.php хранит постоянные настройки плагина: реквизиты подписанта, параметры PDF-штампа, поведение QR-кода и базовое оформление кнопок блока Документ.

Входные данные

  • ФИО, должность и организация подписанта.
  • Угол размещения штампа, цвет, прозрачность, размер шрифта, длина штампа и флаг рамки.
  • Флаг наложения favicon или логотипа сайта на QR-код.
  • Цвет основной кнопки блока, цвет текста основной кнопки, цвет контурной кнопки и скругление кнопок.

Выходные данные

  • Опция WordPress sign_docs_settings.
  • Значения по умолчанию для админской страницы Добавить документ.
  • Значения по умолчанию для полноэкранной модалки Gutenberg-блока.
  • CSS-переменные для кнопок блока Документ на фронте и в редакторе.
  • Ссылки на стандартные экраны WordPress для справочников: категории, типы документов, подразделения и институции.

Контракт

  • Настройки являются defaults, а не источником истины для уже подписанных документов.
  • При подписи реквизиты копируются в meta конкретной записи sign-docs.
  • Изменение настроек не должно менять реквизиты старых документов.
  • Серверная санитизация ограничивает цветовые поля hex-цветами, прозрачность диапазоном 0.1..1, размер шрифта 6..12, ширину штампа 70..160 мм и скругление кнопок 0..9999 px.
  • Настройки кнопок применяются к основным действиям блока: Скачать, Сведения и presentation-mode button.
  • QR-код всегда ведет на страницу проверки, а не на PDF.
  • Сохранять настройки может только пользователь с правом manage_options.
