Module: Site Icon

Модуль includes/class-site-icon.php готовит PNG-копию favicon или логотипа сайта для вставки в центр QR-кода.

Входные данные

  • Attachment ID из опции WordPress site_icon.
  • Fallback attachment ID из theme mod custom_logo.
  • Исходный файл изображения из uploads.

Выходные данные

  • Кэшированный PNG-файл wp-content/uploads/sign-docs/assets/site-icon.png.
  • URL PNG-файла с version query по времени изменения файла.
  • Опция sign_docs_site_icon_cache с ID источника и временем изменения исходного файла.

Контракт

  • PNG пересоздается только если изменился source attachment или mtime исходного файла.
  • Если сервер не смог подготовить PNG, модуль возвращает исходный URL изображения.
  • Браузерная WebP-конвертация в JS остается только fallback-слоем.
