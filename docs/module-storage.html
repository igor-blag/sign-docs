Module: Storage

Модуль описывает файловое хранилище в wp-content/uploads/sign-docs.

Входные данные

  • Путь к файлу исходного PDF.
  • Стандартная директория uploads WordPress.

Выходные данные

  • uploads/sign-docs/year/month/post-id/original.pdf - контрольная копия.
  • uploads/sign-docs/year/month/post-id/stamped.pdf - публичная копия с отметкой.
  • Обе копии документа хранятся рядом в одной папке year/month/post-id.
  • SHA-256 для читаемого файла.

Контракт

  • Исходный файл не изменяется после расчета хеша.
  • Модуль не создает записи WordPress и не принимает HTTP-запросы.
  • Детальная структура year/month/post-id применяется сервисом создания документа.
