Module: Taxonomies

Модуль Sign_Docs_Taxonomies регистрирует таксономии классификации подписанных документов. Все таксономии непубличные (public=false), показываются в админке, доступны через REST.

Зарегистрированные таксономии

sign_doc_category

Категории документов. Иерархическая. Термины по умолчанию:

  • local-act — Локальный акт
  • external-regulation — Внешний нормативный документ
  • other-document — Прочий документ

sign_doc_type

Типы/виды документов. Иерархическая. Двухуровневая структура: родительские категории и дочерние типы.

  • local-acts → local-order (Приказ), local-regulation (Положение), local-rule (Правила), local-program (Программа)
  • external-regulations → external-order (Приказ), external-directive (Распоряжение), external-resolution (Постановление), external-federal-law (Федеральный закон)
  • other-documents → other-document-type (Иное)

При регистрации удаляются устаревшие плоские термины (order, regulation, directive, resolution, federal-law), если они не используются.

sign_doc_department

Структурные подразделения. Иерархическая.

sign_doc_institution

Институции / органы власти, издавшие документ. Неиерархическая (hierarchical=false).

Связь с формами

  • Категория выбирается в форме загрузки и влияет на доступные типы документов.
  • Тип документа привязан к родительской категории: при смене категории список типов фильтруется.
  • Институция — комбинированный ввод: выбор существующего термина или ввод нового (через wp_insert_term).
  • Для локальных актов институция подставляется из настроек организации.

Контракт

  • Таксономии регистрируются на init вместе с CPT.
  • Термины по умолчанию создаются только если их ещё нет (term_exists).
  • Show admin column включено для всех таксономий.
  • Меню таксономий скрыты из админки (remove_taxonomy_menus), доступны только через ссылки со страницы настроек.
