Module: Tests

Модуль автоматизированных проверок фиксирует критичные инварианты Sign Docs без внешних зависимостей. Тесты запускаются обычным PHP CLI и используют минимальные WordPress test doubles.

Запуск

php tests/run.php

Покрываемые контракты

  • Серверный SHA-256 считается по сохраненной контрольной копии original.pdf.
  • prepare создает приватную запись needs_public_copy и не публикует промежуточный документ.
  • complete сохраняет stamped.pdf, audit-поля и публикует только корректный документ.
  • complete отклоняет измененный исходник и записи вне статуса needs_public_copy.
  • Замена документа помечает предыдущую запись как replaced только после успешного завершения новой версии.
  • Удаление CPT через админские фильтры превращается в архивирование, а внутренний rollback сервиса проходит без архивирования.
  • REST write-endpoints требуют capability sign_docs_upload_documents, а complete дополнительно требует edit_post.
  • REST meta schema не раскрывает внутренние пути файлов, хеш исходника, QR payload, IP, user-agent и audit user IDs.

Границы

  • Тесты не поднимают полноценный WordPress и не заменяют будущие integration tests на реальном WordPress test suite.
  • Тесты проверяют серверные контракты PHP-модулей. Браузерный pdf-lib workflow должен проверяться отдельно в UI/integration-сценариях.
