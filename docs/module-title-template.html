Title Template

Модуль Sign_Docs_Title_Template хранит и применяет матрицу сборки названия документа.

Входные данные

  • document_category - категория документа.
  • document_type_term_id или document_type_slug - тип документа.
  • document_type_label, document_date, document_number, document_subject, academic_year, document_institution - реквизиты для шаблона.
  • academic_year хранит готовую фразу периода, например на 2025/26 учебный год или за 2025 год. Быстрые варианты рассчитываются от даты подписания.

Хранение

Правила хранятся в option sign_docs_title_rules. Каждое правило содержит категорию, slug типа документа, список компонентов, разделитель, флаг кавычек для темы и флаг активности.

Выходные данные

Метод compose() возвращает нормализованное название. Если правило не найдено, используется совместимый fallback: поле document_subject с учетом флага include_subject_quotes_in_title.

Админка

Страница Sign Docs -> Матрица названий позволяет выбрать компоненты названия для каждого типа документа. Конфиг также передается в assets/js/admin-upload.js для клиентского предпросмотра.

Форма загрузки содержит одно поле Название и внутренний Комментарий. Комментарий сохраняется как служебное описание и не выводится на публичной странице проверки.
