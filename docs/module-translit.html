Module: Translit

Модуль includes/class-translit.php преобразует кириллическое название документа в латинское имя файла для файловой системы. Файлы с кириллицей в имени могут вызывать проблемы на некоторых хостингах и в URL.

Входные данные

  • Кириллическое название документа (post_title), переданное из формы загрузки или REST API.

Выходные данные

  • Латинское имя файла длиной до 100 символов, пригодное для использования в пути файловой системы.

Контракт

  • Преобразование по стандартной карте: а→a, б→b, … ё→e, ж→zh, ц→ts, ч→ch, ш→sh, щ→sch, э→e, ю→yu, я→ya.
  • Твёрдый и мягкий знак опускаются.
  • Латиница, цифры и дефисы сохраняются; пробелы и небуквенные символы заменяются на дефис.
  • Последовательные дефисы схлопываются.
  • Если результат пуст, возвращается document.
  • Имя файла используется Sign_Docs_Document_Service как file_basename; при наличии basename файлы сохраняются как {basename}.pdf и {basename}-stamped.pdf вместо original.pdf и stamped.pdf.
