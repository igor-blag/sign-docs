Module: Usage Index

Модуль отслеживает, в каких записях и страницах используется Gutenberg-блок sign-docs/document, чтобы поддерживать фильтрацию и сборку мусора по документам CPT sign-docs.

Задачи

  • Индексировать связи document_id -> host_post_id при сохранении контента.
  • Показывать в списке документов колонку использования.
  • Давать фильтр: используется, не используется, битые связи.
  • Показывать в карточке документа список страниц/записей, где документ вставлен.
  • Поддерживать одноразовый backfill индекса для уже опубликованного контента.

Входные данные

  • post_content записей и страниц с Gutenberg-блоками.
  • Атрибут блока postId у блока sign-docs/document.
  • События WordPress: save_post, before_delete_post, transition_post_status.

Выходные данные

  • Таблица БД {prefix}sign_docs_usage с актуальными связями использования.
  • Колонка Used in в списке CPT sign-docs.
  • Админ-фильтр Usage по состоянию использования документа.
  • Метабокс «Используется в записях» на карточке документа.

Инварианты

  • Индекс обновляется инкрементально: для сохраненного host-поста связи пересобираются полностью.
  • Таблица создается или обновляется через lifecycle плагина: activation и upgrade-check по версии, а не на каждом публичном запросе.
  • Индекс учитывает блоки внутри reusable-блоков core/block.
  • Фильтр broken строится по связям на удаленные или перемещенные в корзину host-посты.
