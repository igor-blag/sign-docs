Module: Verification Page

Модуль выводит публичную страницу проверки подписанного документа.

Входные данные

  • Запись CPT sign-docs.
  • Meta-поля документа.

Выходные данные

  • Название документа.
  • Дата и время подписи.
  • Подписант и организация.
  • SHA-256 исходного файла.
  • Ссылка на публичную копию PDF с отметкой.
  • Адрес страницы проверки как данные для QR-кода.

Контракт

  • Страница проверки не должна ссылаться только на файл без отображения хеша и данных записи.
  • Публичный контент экранируется перед выводом.
  • verification_url фиксируется как короткий адрес /signed/{post_id}/.
